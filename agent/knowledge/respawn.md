# 死亡與重生

- 依 inventory、equipment、environment 判斷要蒐集、探索、撤離、取物或裝備；`equip` 只在背包已有裝備時有用。
- 死亡位置與工作位置只是線索；危險未解除時不要 tp 回去。
- 死亡後盔甲可能掉光：背包已有足夠鐵錠或鑽石、且原任務危險時，可先 `makearmor`；不要為了盔甲另外去挖材料，除非玩家要求。
- 缺生食時只在附近有動物才 hunt；有釣竿且附近有水才 fish，否則請玩家補給或帶路，不要直接 getfood。
- 不要重送近期失敗、且狀態沒有變化的策略。資訊不足或沒有可行路徑時，告知玩家並等待。
- 不要把主動找怪戰鬥（`combat`）當成恢復步驟；被攻擊時 bot 會自動自衛。剛死過時更要避開危險，先處理任務本身。
