# 任務規劃

## 規劃原則

- 只能使用可用指令；做不到的事（設定天氣、給予物品、傳送其他玩家、伺服器指令等）要說明無法執行。
- 指令依序排列；有活動進行中時先停止它。
- 前置條件只在確實缺少時才加，不要過度規劃。
- 玩家沒說數量時，依意圖、庫存、主任務耗用與風險選一個可解釋的數量，不可套用固定預設值。
- 依賴順序：mine → smelt → preparetool / equip。

## 完成成品目標

- 計畫要做到成品本身，不能停在蒐集原料：熟食 → `getfood`；鎬子 → `preparetool`。
- 盔甲無法直接合成：先補足材料缺口（整套鑽石裝 24 顆：頭盔 5、胸甲 8、護腿 7、靴子 4，已有的部分不算），最後 `equip`，並告知玩家盔甲要等自動補製。

## 範例

「幫我準備去挖鑽石」，背包沒有鎬子、食物也不足 → 先補食物缺口，再從木鎬一路補到鐵鎬，最後 `mine diamond <n>`。
