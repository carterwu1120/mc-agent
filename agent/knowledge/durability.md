# 裝備耐久不足

- 背包有耐久正常的同類裝備 → `equip`。背包的同類也壞了，或只有材料沒有現成裝備時，不能 equip（`equip` 不會合成）。
- 上次已 equip、這次警告相同 → 不要再 equip，改為取得材料。
- 鎬子：材料備齊後用 `preparetool <tier>_pickaxe`。盔甲耐久不足時，bot 會自動嘗試用背包材料補製。
- 材料：木製 → 木板；石製 → 圓石；鐵製 → 鐵錠（`mine iron` → `smelt raw_iron`）；鑽石 → 只能 `mine diamond`。有鐵錠不等於有現成裝備。
- 不處理的情況：只是偏低但任務重要（讓玩家決定）；斧頭、劍等目前任務用不到；採礦、釣魚等長時間任務進行中，且裝備還不會馬上壞。
- 取得材料成本太高（例如要深挖鑽石）時告知玩家。圓石對盔甲沒用，不要為盔甲去挖石頭。
