# 原地背包整理

背包達 34/36 格時暫停活動，原地整理後繼續同一任務。不回家、不做箱子、不存箱、不挖洞埋垃圾。目標是整理到 28 格以下，避免一恢復就又滿。

## 永遠保留

- 工具、武器、護甲、釣竿、桶、箭、盾
- 食物（含生肉生魚）、燃料（煤、木炭、原木、木板、木棍）
- 貴重物品：礦石、原礦、錠、粒、鑽石、綠寶石、青金石、紅石、石英及它們的方塊
- 必要材料：工作台、熔爐、箱子、火把、線
- 當前任務的目標物，以及未完成步驟會用到或產出的物品

## 建材保留

- 圓石、深板岩碎石、泥土、地獄石、石頭合計至少留 128 個（兩組），用來墊高或搭路到目的地；優先保留圓石。

## 一定可以丟

- 閃長岩、安山岩、花崗岩、凝灰岩、方解石、礫石、燧石、沙、粗泥、鐘乳石、腐肉、蜘蛛眼、骨頭

## 依當前任務判斷

不在上述清單的其他物品（例如羽毛、羊毛、幻翼膜、花、種子），依當前任務與剩餘步驟判斷是否需要：
- 任務或剩餘步驟用得到就保留，用不到才丟。
- 不確定時保留；寧可多一格，也不要丟掉之後需要的東西。
- 只丟到足夠騰出空間為止，不需要清空所有雜項。
